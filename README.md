# ♟️ Antigravity Chess AI — 2D/3D Interactive Chess Web App

Интерактивное шахматное веб-приложение нового поколения с ИИ-ботом Stockfish, анализом ходов в реальном времени, 2D/3D режимами доски и бейджами качества ходов в стиле Chess.com.

![Preview](public/favicon.svg)

---

## 🚀 Основные возможности

- **🎮 Два режима отображения (2D и 3D)**:
  - **2D вид**: Плоская адаптивная доска с векторными фигурами Staunton (cburnett), подсветкой легальных ходов, шаха и последнего хода.
  - **3D вид**: Изометрическая сцена на Three.js с процедурными фигурами, тенями, управляемым углом камеры (вращение ЛКМ, зум колесиком и кнопками, сброс) и кликом по фигурам.
  - Мгновенное переключение между 2D и 3D без сброса позиции и часов.
- **🤖 Игра с ботом**:
  - 8 уровней сложности (от новичка 600 Elo до гроссмейстера 2850 Elo).
  - Выбор стороны: Белые / Черные / Случайно.
  - Контроль времени: Пуля (1+0), Блиц (3+0, 5+3), Рапид (10+0) или без ограничения.
  - Реалистичные звуки через Web Audio API (ход, взятие, шах, мат, превращение, зевок).
- **💎 Анализ ходов в реальном времени (Chess.com Style)**:
  - 💎 Brilliant (Бриллиантовый — жертва с решающим перевесом)
  - ⭐️ Best (Лучший ход)
  - 👍 Excellent / Good (Отличный / Хороший)
  - ❓ Inaccuracy (Неточность)
  - ⚠️ Mistake (Ошибка)
  - ❌ Blunder (Зевок)
  - **Evaluation Bar (Шкала оценки)** в реальном времени с отображением перевеса в пешках или мата.
- **🎨 Кастомизация и темы**:
  - 5 тем доски: Классическая, Благородное дерево, Киберпанк Неон, Мрамор, Минималистичная темная.
  - 4 стиля фигур: Staunton, Neo, Pixel Art, Wood Carved.
  - Сохранение настроек в `localStorage`.
- **📋 Дополнительно**:
  - Журнал партии в нотации SAN с перемоткой ходов.
  - Экспорт/Импорт FEN и PGN с возможностью скачать `.pgn` файл.

---

## 🛠️ Стек технологий

- **Фронтенд**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **Шахматная логика**: `chess.js`
- **Движок**: Stockfish Online API + Stockfish.js Web Worker + локальный Minimax (Alpha-Beta)
- **3D-графика**: Three.js

## 📦 Установка и запуск

```bash
# Клонировать репозиторий:
git clone https://github.com/ВАШ_ЛОГИН/chess-app.git
cd chess-app

# Установить зависимости:
npm install

# Запустить локальный сервер:
npm run dev
```

Откройте в браузере: `http://localhost:5173/`
